# claude-plugins

Claude Code plugins by adamff-dev.

## Install

```text
/plugin marketplace add adamff-dev/claude-plugins
/plugin install cwd-path@adamff-claude-plugins
```

## Plugins

- **cwd-path**: the directory Claude Code is working in, at the bottom right of the prompt footer, next to the permission mode. Home shown as `~`, long paths cut from the left. See [plugins/cwd-path](plugins/cwd-path/README.md).
